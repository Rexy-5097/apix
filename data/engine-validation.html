SYNTHETIC FIXTURE - NOT A MARKET MEASUREMENT

Engine validation — synthetic fixture

This page contains no market data and no APIx index value. It exists to show that the index engine computes. Every figure below is derived from controlled test data defined in tests/test_pipeline_14_day.py, the fixture CI runs on every commit. Prices in the fixture are chosen so the arithmetic is hand-checkable. Values are index points (base 100) — there are no currency figures anywhere on this page.

Spec D.3 requires |M| ≥ 3 before a relative is defined. 2 link(s) moved and 3 were flat. The Jevons index of items all scaled by k is exactly k (INV-4b), and the fixture scales every price by 1.04 — so the moved relatives are verifiable by hand. The flat links report exactly 1.000000 rather than "undefined": a measured no-change and an absent measurement are different statements, and the engine keeps them apart.

The engine raises rather than dropping the state or quietly re-dating it. This is the same refusal discipline that keeps the real panel's index PENDING — shown here on input where it can actually be triggered.

Why this is not an APIx result

APIx's real DEL–BOM panel holds one collection wave. Spec §C.1 is locked at I(c,t) = I(c,t−7)·J(c,t), so no matched pair exists and no real index value is computed or published. This page demonstrates the machinery on controlled input; it makes no claim about airfare.
